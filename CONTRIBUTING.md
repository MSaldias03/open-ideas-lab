# Contributing / Cómo contribuir

## Español
Se aceptan comentarios, bibliografía, críticas, diseños, prototipos y nuevas ideas mediante issues o pull requests. Para proponer una implementación, describe el alcance, los riesgos, los permisos sobre contenidos y cómo protegerías a los menores. No publiques datos reales de niños, grabaciones, información privada ni materiales de terceros sin licencia.

**Atribución:** al reutilizar o adaptar documentación original, cumple CC BY 4.0: atribuye autoría, enlaza la licencia e indica cambios. Citar este repositorio es una forma práctica de hacerlo. La licencia no concede propiedad sobre ideas abstractas ni cubre automáticamente el código de futuros proyectos.

**Contribuciones:** al enviar texto al repositorio, confirma que puedes compartirlo bajo CC BY 4.0 y que identificas cualquier contenido con licencia distinta. Para código futuro, acuerda primero una licencia de software separada.

## English
Issues and pull requests with feedback, references, critiques, designs, prototypes and new ideas are welcome. Implementation proposals should describe scope, safety, media rights and child protection. Never post real children's data, recordings, private information or unlicensed third-party content.

**Attribution:** reuse/adaptation of original documentation under CC BY 4.0 requires credit, a license link and indication of changes. Linking to this repository is a practical way to credit the source. The license does not grant ownership of abstract ideas or automatically license future code.

**Contributions:** by submitting documentation, confirm you have the rights to share it under CC BY 4.0 and identify differently licensed material. Agree on a separate software license before accepting code.
